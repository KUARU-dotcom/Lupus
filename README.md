# Lupus Alpha v0.1

**Статус:** Прототип для проверки гипотезы  
**Цель:** Проверить, что LLM (1.5B-7B) пишет на Lupus правильнее, чем на Python  
**Ограничения:** Только минимальное подмножество языка (без типов, без async, без FFI)

## Что работает

- [x] Переменные (`define`)
- [x] Функции (`define (fn ...)`)
- [x] Арифметика (`+`, `-`, `*`, `/` — только int)
- [x] Условный оператор (`if`)
- [x] Циклы (`while`)
- [x] Списки (`list`, `nth`, `length`)
- [x] Ввод-вывод (`print`)

## Что НЕ работает (временно)

- ❌ Статическая типизация (всё динамически)
- ❌ Модули (`senko`, `texas`, `kaltsit`)
- ❌ Асинхронность (`async/spawn`, каналы)
- ❌ `match`, `if-let`, `cond`
- ❌ `Option`, `Result`
- ❌ FFI (вызов Python из Lupus)
- ❌ Встроенные тесты (`test`)
