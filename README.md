# Lupus Language

**Lupus** — язык программирования, спроектированный для LLM (1.5B–7B параметров).  
Цель: снизить количество синтаксических ошибок, логических ошибок и галлюцинаций при генерации кода нейросетями.

## Гипотеза

**Ожидание:** LLM (1.5B–7B) будет писать на Lupus с минимум на **20% меньше ошибок**, чем на Python (синтаксических, логических, галлюцинаций).

**Проверка:**
1. Замеряем LLM на 100 задачах на Python.
2. Замеряем на тех же задачах на Lupus (Alpha v0.1).
3. Сравниваем.

---

## План развития

### Этап 1 (сейчас) — Alpha v0.1
- Минимальный интерпретатор на Python.
- Без типов, без async, без FFI, без модулей.
- Только базовые конструкции: `define`, `if`, `while`, `+`, `-`, `*`, `/`, `list`, `print`.
- **Цель:** проверить гипотезу.

### Если гипотеза подтвердится (+20% и выше)
- Развитие языка до v1.0:
  - Статическая типизация, `match`, `Option`/`Result`.
  - Модули: `senko` (math), `texas` (net), `kaltsit` (file), `amiya` (async), `w` (test).
  - FFI для вызова Python.
  - Переписывание на **Rust** (независимый бинарник, скорость, безопасность).
- Расширение функционала, независимость от Python.

### Если гипотеза не подтвердится
- Попробовать изменить дизайн языка (другая парадигма, синтаксис).
- Если не помогает — **заморозить эксперимент до 2027–2028**.
- Причина: к 2027–2028 LLM станут умнее, появятся новые архитектуры, и гипотезу можно будет перепроверить с новыми данными.

---

## Почему язык не для людей

Синтаксис Lupus (префиксный, минималистичный) **некрасив для людей**, но **проще для LLM**:
- Нет неоднозначностей.
- Нет магии.
- Минимум галлюцинаций.

Lupus — это язык-компаньон для LLM, а не замена Python для человека.
