# Lupus

> **Язык программирования, созданный в диалоге. От LLM — для LLM.**
>
> *Эксперимент: сможет ли LLM спроектировать язык? Сможет ли язык, созданный LLM, работать лучше для LLM?*

---

## О проекте

**Lupus** — экспериментальный язык программирования общего назначения, разработанный для оптимизации работы с LLM (большими языковыми моделями).

**Версия:** v0.2 (Rust Rewrite) · **Статус:** Интерпретатор в активной разработке.

Гипотеза эксперимента состоит из трёх частей:

1. Сможет ли LLM спроектировать полноценный язык — от грамматики и системы типов до FFI и стандартной библиотеки?
2. Сможет ли LLM реализовать этот язык — интерпретатор, парсер, типичекер, runtime?
3. Будет ли LLM (1.5B–7B параметров) делать на 20%+ меньше ошибок на Lupus, чем на Python?

Если все три пункта выполнятся, это докажет, что LLM может выступать не только инструментом, но и **архитектором языков**.

## Быстрый старт

### Из исходников (Rust)

```bash
git clone https://github.com/KUARU-dotcom/Lupus
cd Lupus

# Сборка
cargo build --release

# Запуск программы
./target/release/lupus examples/calc.lupus

# Интерактивный REPL (планируется в v0.3)
# ./target/release/lupus --repl
```

**Требования:** Rust 1.70+. Никаких внешних зависимостей.

### Из бинарных файлов

Скачайте готовые бинарники для Linux/Windows со страницы [Releases](https://github.com/KUARU-dotcom/Lupus/releases).

```bash
# Linux/macOS
./lupus examples/calc.lupus

# Windows
lupus.exe examples/calc.lupus
```

### Устаревший прототип (Python v0.1)

Для использования исходного Python-прототипа переключитесь на ветку `prototype`:

```bash
git checkout prototype
python lupus_proto.py examples/calc.lupus
```

## Особенности

- **Префиксный синтаксис** — `(define x 42)`, `(+ 1 2)`. Чистый однозначный AST без синтаксического сахара.
- **Статическая типизация** — алгоритм вывода типов (планируется Hindley-Milner). Типы выводятся автоматически.
- **Паттерн-матчинг** — `match` с проверкой исчерпываемости.
- **Функции и лямбды** — `define`, `lambda`, замыкания.
- **Управление потоком** — `if`, `while`, `define-mutable`, `set!`.
- **Встроенные типы** — целые числа, вещественные числа, строки, списки, логические значения.
- **Встроенные функции** — арифметика, работа со строками, со списками, печать.
- **Детерминированный AST** — предназначен для обучения LLM на чистом синтаксисе.

## Примеры кода

### Базовая арифметика и определения

```lisp
(define pi 3.14159)
(define radius 10.0)
(define area (* pi (* radius radius)))
(print area)  ; => 314.159
```

### Функции

```lisp
(define (square x)
  (* x x))

(define (circle-area r)
  (* 3.14159 (* r r)))

(print (square 5))           ; => 25
(print (circle-area 10.0))   ; => 314.159
```

### Условия и циклы

```lisp
(define (abs x)
  (if (< x 0) (- x) x))

(define (factorial n)
  (define-mutable result 1)
  (define-mutable i 1)
  (while (<= i n)
    (set! result (* result i))
    (set! i (+ i 1)))
  result)

(print (factorial 5))  ; => 120
```

### Списки и обработка данных

```lisp
(define numbers (list 1 2 3 4 5))
(print (car numbers))      ; => 1
(print (length numbers))   ; => 5
(print (reverse numbers))  ; => (5 4 3 2 1)
```

### Лямбды и замыкания

```lisp
(define (make-adder x)
  (lambda (y) (+ x y)))

(define add5 (make-adder 5))
(print (add5 3))  ; => 8
```

## Архитектура интерпретатора

```
┌──────────────────────────────────────────────────────┐
│  CLI: lupus [--lenient-parens] файл.lupus            │
├──────────────────────────────────────────────────────┤
│  Lexer (src/lexer.rs)                                │
│  Преобразует текст в токены                          │
├──────────────────────────────────────────────────────┤
│  Parser (src/parser.rs)                              │
│  Преобразует токены в AST (Abstract Syntax Tree)     │
├──────────────────────────────────────────────────────┤
│  Interpreter (src/interpreter.rs)                    │
│  Выполняет AST в окружении (tree-walk интерпретатор) │
├──────────────────────────────────────────────────────┤
│  Runtime (src/value.rs, src/environment.rs)          │
│  Хранит значения, переменные, замыкания              │
└──────────────────────────────────────────────────────┘
```

### Структура проекта

```
src/
├── main.rs              # Точка входа CLI
├── lib.rs               # Публичный API библиотеки
├── lexer.rs             # Лексический анализатор
├── parser.rs            # Синтаксический анализатор
├── ast.rs               # Определение AST
├── interpreter.rs       # Интерпретатор
├── value.rs             # Представление значений (Value)
├── environment.rs       # Окружение переменных (Environment)
├── error.rs             # Обработка ошибок
└── builtins/            # Встроенные функции
    ├── arithmetic.rs    # Планируется
    ├── io.rs            # Планируется
    └── list.rs          # Планируется
```

## Поддерживаемый синтаксис (v0.2)

### Определения и переменные

| Форма | Пример | Описание |
|-------|--------|---------|
| `define` | `(define x 42)` | Определить переменную |
| `define-mutable` | `(define-mutable x 0)` | Определить изменяемую переменную |
| `set!` | `(set! x 10)` | Изменить значение переменной |

### Функции

| Форма | Пример | Описание |
|-------|--------|---------|
| `define` с функцией | `(define (f x) (+ x 1))` | Определить функцию |
| `lambda` | `(lambda (x) (+ x 1))` | Анонимная функция |

### Управление потоком

| Форма | Пример | Описание |
|-------|--------|---------|
| `if` | `(if (> x 0) "pos" "neg")` | Условное ветвление |
| `while` | `(while (< i 10) (set! i (+ i 1)))` | Цикл while |

### Встроенные функции

| Функция | Примеры |
|---------|---------|
| Арифметика | `(+ 1 2)`, `(- 5 3)`, `(* 2 3)`, `(/ 10 2)` |
| Сравнение | `(= a b)`, `(< x y)`, `(> x y)`, `(<= x y)`, `(>= x y)` |
| Логика | `(and true false)`, `(or true false)`, `(not true)` |
| Строки | `(string-append "a" "b")`, `(string-length "hello")` |
| Списки | `(list 1 2 3)`, `(car lst)`, `(cdr lst)`, `(length lst)`, `(reverse lst)` |
| Вывод | `(print x)`, `(println x)` |

## Историческая информация

### Ветки

| Ветка | Содержимое | Статус |
|-------|-----------|---------|
| `main` | Этот файл. Текущая документация v0.2. | Активна |
| `prototype` | Исходный Python-прототип (v0.1/v0.1e). | Архив |
| `specification` | Полная спецификация языка v1.0 (EBNF). | Архив |

### Версионность

- **v0.1 / v0.1e** — Python прототип (ветка `prototype`). Убрана из производства.
- **v0.2** — Полная переписка на Rust (текущая ветка `main`). Активная разработка.
- **v1.0** — Планируемый стабильный релиз с полным набором возможностей.
