# Lupus Programming Language - Alpha v0.1 Prototype

Минимальный рабочий прототип языка программирования **Lupus**, реализованный на Python.

## 📋 Описание

**Lupus** — экспериментальный язык программирования, основанный на Lisp-синтаксисе (S-выражения). 
Этот прототип (Alpha v0.1) представляет собой полностью функциональный **tree-walk интерпретатор** для базового подмножества языка.

### ✨ Основные возможности

- ✅ **Переменные** - определение неизменяемых и изменяемых переменных
- ✅ **Функции** - определение и вызов функций, рекурсия
- ✅ **Замыкания** - лексическая область видимости с поддержкой замыканий
- ✅ **Операторы** - арифметика, сравнение, логические операции
- ✅ **Управление потоком** - условия (if) и циклы (while)
- ✅ **Структуры данных** - списки целых чисел
- ✅ **Ввод-вывод** - вывод на экран и преобразование типов
- ✅ **Интерпретатор** - запуск файлов и интерактивный REPL режим

## 🎯 Поддерживаемые конструкции

### Синтаксис

```lisp
;; Комментарии
(define x 10)                    ;; Константа
(define-mutable y 20)            ;; Переменная
(set! y 25)                      ;; Присваивание

(define (add a b) (+ a b))       ;; Функция
(add 5 3)                        ;; Вызов функции

(if (> x 0) "pos" "neg")        ;; Условие
(while (< i 10) (set! i ...))   ;; Цикл
```

### Встроенные функции

```lisp
(+ 1 2)          ;; Сложение
(- 5 3)          ;; Вычитание
(* 4 2)          ;; Умножение
(/ 10 2)         ;; Деление
(= a b)          ;; Равно
(< a b)          ;; Меньше
(> a b)          ;; Больше
(<= a b)         ;; Меньше или равно
(>= a b)         ;; Больше или равно
(!= a b)         ;; Не равно
```

### Работа со списками и вводом-выводом

```lisp
(list 1 2 3)     ;; Создание списка
(nth lst 0)      ;; Элемент по индексу
(length lst)     ;; Длина списка
(print "text")   ;; Вывод строки
(int->str 42)    ;; Преобразование в строку
(string-append "a" "b") ;; Конкатенация строк → "ab"
(and true false) ;; Логическое И → false
(or  false true) ;; Логическое ИЛИ → true
(not false)      ;; Логическое НЕ → true
(% 7 2)          ;; Остаток от деления → 1
```

## 🏗️ Архитектура

Интерпретатор состоит из трёх основных компонентов:

### 1. **Лексер** (Tokenizer)
- Разбор исходного кода на токены
- Поддержка: чисел, строк, символов, скобок, комментариев

### 2. **Парсер** (Parser)
- Построение абстрактного синтаксического дерева (AST)
- Использование рекурсивного спуска
- Поддержка S-выражений (S-expressions)

### 3. **Интерпретатор** (Evaluator)
- Выполнение AST методом tree-walk
- Управление окружением переменных
- Поддержка замыканий (lexical scoping)
- Обработка встроенных функций и специальных форм

## ⚠️ Известные ограничения

- **Только целые числа** - нет поддержки вещественных чисел
- **Нет исключений** - ошибки приводят к завершению программы
- **Нет модулей** - всё выполняется в одном глобальном пространстве
- **Нет объектов** - только примитивные типы данных
- **Нет стандартной библиотеки** - только встроенные функции
