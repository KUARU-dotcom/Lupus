# Lupus Alpha v0.1 - Документация

## Обзор

**Lupus** — экспериментальный язык программирования на основе Lisp-синтаксиса.  
**Lupus Alpha v0.1** — минимальный рабочий прототип с поддержкой базовых операций.

Реализация включает:
- **Лексер** — разбор исходного кода на токены
- **Парсер** — построение абстрактного синтаксического дерева (AST)
- **Интерпретатор** — tree-walk выполнение AST с лексическим скопингом

## Установка и запуск

### Требования
- Python 3.10 или выше
- Только стандартная библиотека Python (без внешних зависимостей)

### Запуск файла Lupus

```bash
python lupus_proto.py имя_файла.lupus
```

### Интерактивный режим REPL

```bash
python lupus_proto.py
```

Результат каждого выражения автоматически печатается:

```
lupus> (define x 10)
lupus> (+ x 5)
15
lupus> (string-append "x = " (int->str x))
x = 10
```

## Синтаксис

### 1. Комментарии

```lisp
;; Это комментарий
```

### 2. Переменные

```lisp
;; Неизменяемая (define)
(define x 10)
(define name "Lupus")

;; Изменяемая (define-mutable + set!)
(define-mutable y 20)
(set! y 25)
```

### 3. Функции

```lisp
;; Однострочное тело
(define (add a b) (+ a b))

;; Многострочное тело — все выражения выполняются, возвращается последнее
(define (log-double n)
  (print (string-append "n = " (int->str n)))
  (* n 2))

;; Функция без параметров
(define (greet) (print "Hello!"))

;; Рекурсия
(define (factorial n)
  (if (= n 0)
    1
    (* n (factorial (- n 1)))))

;; Вызов
(factorial 5)   ;; → 120
(greet)         ;; → "Hello!"
```

### 4. Арифметика

```lisp
(+ 1 2 3)      ;; 6    — сложение, любое число аргументов
(- 10 3)       ;; 7    — вычитание
(- 5)          ;; -5   — унарный минус
(* 3 4)        ;; 12   — умножение
(/ 10 3)       ;; 3    — целочисленное деление
(% 10 3)       ;; 1    — остаток от деления
```

### 5. Сравнение

```lisp
(= 5 5)        ;; true
(!= 3 5)       ;; true
(< 3 5)        ;; true
(> 5 3)        ;; true
(<= 5 5)       ;; true
(>= 5 5)       ;; true
```

### 6. Логика

```lisp
(and (> 5 3) (< 1 2))   ;; true  — короткое замыкание: если первый false — второй не вычисляется
(or  (= 1 2) (= 2 2))   ;; true  — короткое замыкание: если первый true — второй не вычисляется
(not (= 1 2))            ;; true
```

### 7. Строки

```lisp
(string-append "Hello" ", " "World!")   ;; "Hello, World!"
(int->str 42)                           ;; "42"
```

### 8. Условия

```lisp
(if (> x 0)
  (print "Положительное")
  (print "Не положительное"))
```

Семантика: `false` и `0` — ложь; всё остальное (включая непустые строки и списки) — истина.

### 9. Циклы

```lisp
;; while
(define-mutable i 0)
(while (< i 5)
  (print (int->str i))
  (set! i (+ i 1)))
;; Выведет: 0 1 2 3 4
```

### 10. Begin — последовательность

```lisp
(begin
  (print "шаг 1")
  (print "шаг 2"))
;; Возвращает значение последнего выражения
```

`begin` используется там, где синтаксически нужно одно выражение, но нужно выполнить несколько:

```lisp
(if (> x 0)
  (begin
    (print "положительное")
    (set! x (- x 1)))
  (print "не положительное"))
```

### 11. Списки

```lisp
(define lst (list 1 2 3 4 5))
(nth lst 0)       ;; 1 — элемент по индексу (0-based)
(length lst)      ;; 5 — длина
```

Списки могут содержать значения любых типов (числа, строки, другие списки).

### 12. Вывод

```lisp
(print "Привет, мир!")   ;; печатает строку с переводом строки
(print (int->str 42))    ;; печатает "42"
```

## Встроенные функции — полная таблица

| Функция | Сигнатура | Описание | Пример |
|---------|-----------|----------|--------|
| `+` | `(+ a b ...)` | Сложение | `(+ 1 2 3)` → 6 |
| `-` | `(- a b ...)` / `(- a)` | Вычитание / унарный минус | `(- 10 3)` → 7, `(- 5)` → -5 |
| `*` | `(* a b ...)` | Умножение | `(* 2 3)` → 6 |
| `/` | `(/ a b)` | Целочисленное деление | `(/ 10 3)` → 3 |
| `%` | `(% a b)` | Остаток от деления | `(% 7 2)` → 1 |
| `=` | `(= a b)` | Равно | `(= 5 5)` → true |
| `!=` | `(!= a b)` | Не равно | `(!= 3 5)` → true |
| `<` | `(< a b)` | Меньше | `(< 3 5)` → true |
| `>` | `(> a b)` | Больше | `(> 5 3)` → true |
| `<=` | `(<= a b)` | Меньше или равно | `(<= 5 5)` → true |
| `>=` | `(>= a b)` | Больше или равно | `(>= 5 5)` → true |
| `and` | `(and ...)` | Логическое И (короткое замыкание) | `(and true false)` → false |
| `or` | `(or ...)` | Логическое ИЛИ (короткое замыкание) | `(or false true)` → true |
| `not` | `(not x)` | Логическое НЕ | `(not false)` → true |
| `string-append` | `(string-append ...)` | Конкатенация строк | `(string-append "a" "b")` → "ab" |
| `int->str` | `(int->str n)` | Число в строку | `(int->str 42)` → "42" |
| `list` | `(list ...)` | Создание списка | `(list 1 2 3)` |
| `nth` | `(nth lst i)` | Элемент по индексу | `(nth lst 0)` → первый |
| `length` | `(length lst)` | Длина списка | `(length lst)` → 5 |
| `print` | `(print str)` | Вывод строки | `(print "Hello")` |

## Типы данных

| Тип | Примеры | Примечание |
|-----|---------|------------|
| `int` | `42`, `-10`, `0` | Целые числа (Python int) |
| `str` | `"Привет"`, `""` | Строки в двойных кавычках |
| `list` | `(list 1 2 3)` | Разнородные списки |
| `bool` | результат сравнений | `true`/`false` через Python bool |

## Обработка ошибок

При ошибке интерпретатор выводит сообщение на русском и завершается с кодом 1:

```
Ошибка выполнения: Переменная не определена: x
Ошибка выполнения: Деление на ноль
Ошибка выполнения: Индекс вне диапазона: 10
Ошибка парсера на строке 3: Неожиданный конец файла
```

## Ограничения v0.1

1. **Только целые числа** — float не поддерживается
2. **Нет модулей** — весь код в одном пространстве имён
3. **Нет исключений** — ошибки завершают программу
4. **Нет объектов и структур** — только примитивные типы
5. **Нет TCO** — глубокая рекурсия (1000+) вызовет Python RecursionError
